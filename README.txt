CYBER DETECTIVE – المحقق الرقمي
================================
موقع توعوي عربي تفاعلي عن الأمن السيبراني.

طريقة التشغيل:
1) فك ضغط الملف ZIP.
2) افتح مجلد Cyber_Detective.
3) اضغط مرتين على index.html لفتح الموقع في المتصفح.
لا يحتاج إلى Python أو Flask أو قاعدة بيانات.

النشر للحصول على رابط عام:
1) افتح https://app.netlify.com/drop من المتصفح.
2) سجّل الدخول أو أنشئ حسابًا.
3) اسحب مجلد Cyber_Detective بعد فك الضغط إلى صفحة النشر (أو اتبع تعليمات رفع المجلد).
4) انتظر اكتمال النشر؛ سيظهر رابط عام يمكنك مشاركته.
قد تختلف خطوات الواجهة، ويمكن تغيير اسم الموقع من إعدادات Netlify.

ملاحظات الأمان والخصوصية:
- فاحص الرسائل يعمل محليًا داخل المتصفح بقواعد إرشادية بسيطة.
- لا يفتح الروابط ولا يتصل بمصادر استخبارات تهديدات، ولا يستطيع إثبات أن رابطًا آمن أو ضار.
- لا يوجد رفع للرسائل أو تخزين لها.
- المحتوى تثقيفي عام وليس بديلًا عن البنك أو الجهات المختصة أو الدعم الفني.
- يفضّل مراجعة المعلومات وتحديثها دوريًا قبل الاستخدام العام.
